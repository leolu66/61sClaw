## 二、红杉合伙人主旨演讲（Pat Grady / Sonya Huang / Constantine Buhler）

### 2.1 三个"前所未有"

**1. 最大的浪潮**
- 传统软件 TAM ≈ 6500亿，云服务 ≈ 4000亿
- AI切入的是 **服务市场** — 仅美国法律服务就达4000亿 = 整个软件行业
- **方向性数字：10万亿美元**（"可能是5万亿，也可能是50万亿"）

**2. 最快的浪潮**
- "以前需要100年才能建出来的东西，现在100天就有可能"
- 赛车比喻：晴天超不了15辆车，但**雨天可以**。现在基础模型正在下能力的大雨

**3. 最不同的浪潮**
- 互联网/云/移动 = **通信革命**（改变分发）
- **AI = 计算革命**（改变处理）
- 通信革命地基稳定，AI"地板每天都在动"
- ❗ **更快的马（10-40%）→ 汽车（10-40倍）**

### 2.2 商业 AGI 的定义

> "如果你能派遣一个智能体去做一项工作，它能在遇到故障后自我修复并持续工作直到完成——这就是商业意义上的通用人工智能。"

**功能性AGI三要素（Sonya Huang）：**
1. **推理和规划** — 基线水平的直觉和即兴思考
2. **采取行动** — 调用工具、搜索、写作、编译
3. **朝着目标迭代** — 持久性，长时间任务+失败恢复

### 2.3 三个转折点

| 时间 | 事件 | 意义 |
|------|------|------|
| 2022.11 | ChatGPT | 预训练的力量 |
| 2024-2025 | o1 模型 | 推理时间计算，第二条缩放定律 |
| 2026 | Claude Code / 长周期智能体 | **"硬断裂"，不连续的变化——汽车已来** |

### 2.4 MADS 框架（给创业者的竞争力支柱）

**M — Moats（护城河）**
- 不要从技术出发，要从**客户需求**出发
- "客户需求变化速度远不及技术演进速度"

**A — Affordance（可供性）**
- 创造"无需解释"的体验——像锤子一样，2岁小孩拿到就知道敲
- "Claude Code 很强大，但让普通财富500强员工打开终端试试"

**D — Diffusion（扩散）**
- 模型能力扩散到市场的速度远慢于创造速度
- 这个**扩散鸿沟**就是应用层公司的巨大套利空间

> "没有领先是稳固的，但这也意味着任何人都可以赢。"

### 2.5 智能体进化阶梯（以编程为例）

| 阶段 | 模式 | 人类参与 |
|------|------|---------|
| 2023 | 行内补全（Tab补全） | AI辅助人 |
| 现在 | 智能体式开发 | 人指挥Agent |
| 正在发生 | **异步后台Agent / Agent衍生Agent** | 管理式 |
| 前沿 | **黑灯工厂**（无人审查推生产） | 完全自动化 |

### 2.6 认知工业革命（Constantine Buhler）

> "地球上99.9%的认知工作将由机器完成。"

**"铝时刻"比喻：**
- 19世纪铝比黄金还贵，美国为华盛顿纪念碑封顶用100盎司铝，放在Tiffany展出
- 电解法发明后，铝变成包糖果的锡纸
- **铝 = 智能，电解 = AI**。博士级能力将被瞬间调用，用完即弃

**三影响：**
1. 智能成为廉价商品
2. **异类设计时代** — 机器逻辑不同于人类直觉
3. 催生新科学——将神经元与Token系统化、公式化

### 2.7 人是万物的尺度

> "摄影没有终结绘画，反而催生了印象派与表现主义。当机器承揽了所有工作，人与人的联结与情感体验将成为价值的终极来源。"

## 三、Boris Cherny（Claude Code 之父）

### 3.1 七个核心判断

**判断一：代码不再稀缺**
> "工程师的价值，从会不会写代码，变成了会不会拆任务、会不会把目标讲清楚、会不会验收结果、会不会管理 Agent。"

- 2026年至今**没有手写过一行代码**，最高纪录一天150个PR
- 大部分工作在手机上完成，Claude App 常驻5-10个会话

**判断二：编程从专业技能→基础能力**
- 类比印刷术：印刷术前仅10%识字，50年出版超过去1000年总和
- "以后写代码会变得像发短信一样简单"
- **Claude Code 自己的代码库，一年后可能只剩100行左右**

**判断三：判断力 > 执行力**
> "最合适写会计软件的是会计师而不是工程师，因为编程是简单部分，懂业务才是难的部分。"

- AI抹平执行门槛后，**产品感觉 + 领域理解 = 真正稀缺**
- 未来的通才是**跨学科通才**（产品+设计+工程+数据）

**判断四：SaaS 护城河被重写**
- 借用《7 Powers》框架：**切换成本+流程效力**被AI削弱，**网络效应+规模经济+独占资源**不受影响
- SaaS不会死，但靠"迁移太痛苦"留客户的那些会死

**判断五：初创团队无历史包袱优势**
- 大公司：历史包袱重、组织惯性大
- 小团队：AI原生，零技术债务
- **速度不再是护城河**（AI拉齐所有人速度），真正的壁垒是：专有数据、行业理解、信任关系

**判断六：MCP 将成为新连接层**
> "如果模型是大脑，MCP 就是让它能动起来的神经系统。"

- MCP = AI 时代的 API——但模型直接理解使用，无需人为适配
- Anthropic 内部，员工已不再直接消息，而是让各自加持AI的 Claude 之间通过Slack沟通

**判断七：Computer Use 解决遗留系统自动化**
- 大量老旧系统没有API，Computer Use让AI像人一样操作屏幕
- Claude Sonnet 4.5 在 OSWorld 基准 61.4%（之前42.2%）

### 3.2 Claude Code 诞生秘史

- 2024年底在Anthropic Labs孵化，前6个月"惨不忍睹"（自己仍写90%）
- **2026年5月 Opus 4 → 指数增长**
- 每次模型升级（4.5→4.6→4.7），使用量陡升
- 选择TypeScript+React：当时模型对此训练数据最多
- 核心洞见：**产品过剩（Product Overhang）**——模型已能做到，但产品还没接住

### 3.3 工作实况

- 一天提交150个PR，每天跑几百个Agent，晚上几千个做异步深度任务
- 几十个 Loop 在跑：自动修CI、自动变基、每30分钟抓Twitter反馈聚类
- 刚推出 **Routines**（服务端Loop），合上电脑也能继续跑

### 3.4 创业黄金时代

> "现在你可以是一家微型公司，却构建出与巨头等值的价值。创业公司的数量将暴增10倍。"

## 四、Andrej Karpathy（Software 3.0）

### 4.1 软件三大范式

| 范式 | 核心 |
|------|------|
| Software 1.0 | 人写显式代码，机器按规则执行 |
| Software 2.0 | 神经网络，人设计数据集和目标函数 |
| **Software 3.0** | **人写提示词，模型本身是可被自然语言编程的解释器** |

### 4.2 核心洞察

> "上下文窗口就是程序。你扔给模型的那整段上下文——图片、需求、约束、错误日志、文档——就是你对这台大语言模型解释器的杠杆。"

**经典案例 — MenuGen：**
- 传统做法：拍菜单→文字识别→生图→渲染→数据库→前端
- 进阶做法：直接把照片丢给Gemini，一句话指令，**原图渲染菜品图**
- "我整个MenuGen是多余的。它不应该存在。输入是一张图，输出是一张图，中间不需要应用。"

### 4.3 锯齿状智能（Jagged Intelligence）

> "同一个模型能重构10万行代码，却可能在'走路还是开车去50米外的洗车店'这种常识问题上出错。"

- AI在可验证领域（代码/数学）通过强化学习得到强化
- 在训练数据分布之外，能力断崖式下降
- **峰值智能 ≠ 通用能力**

### 4.4 Vibe Coding vs Agentic Engineering

| | Vibe Coding | Agentic Engineering |
|--|-------------|-------------------|
| 目标 | **抬高地板**，让所有人都能做出东西 | **保住天花板**，保证质量和安全 |
| 模式 | 自由生成，随性而为 | 工程纪律，安全底线 |
| 适用 | 原型/个人项目 | 生产环境/商业应用 |

> "智能体是超级实习生：能力强、会犯错、有点脆弱、极其强大。专业工程师必须死守三条底线：架构设计 + 审美品位 + 安全边界。"

### 4.5 新招聘考法

- 别考手写算法
- 新考法：给大项目 + 挂10个编程智能体当红队攻击
- 测的是：把模糊目标变清晰规格、指挥智能体完成大规模工程、在Agent生成的代码里保住判断力

> "真正擅长这件事的人，远超10倍工程师。"

## 五、Greg Brockman（OpenAI 联合创始人）

### 5.1 核心商业模式

> "我们的业务很简单：买算力、租算力、建算力，加利润率转售。"

- GPU有效闲置获取率 ≈ **0%**
- 内部团队用**领先外界1-2代的未发布模型**，形成生态碾压
- 暴力计算已推导出让顶尖物理学家惊叹的新公式

### 5.2 人类注意力 = 新瓶颈

> "当智能体可以自主工作时，**人类注意力将成为整个经济体中最稀缺的资源**。"

**Codex案例：** 装包出错→AI在Slack求助→2分钟没回应→AI自动升级ping对方经理。逻辑合理但社交不合适。

### 5.3 上下文成为新竞争关键

- Chronicle 工具：实时记录用户每个动作，让AI拥有"记忆"
- "你居然花那么多时间在跟你的电脑解释发生了什么。这没道理。"
- 对创业者：构建让AI深度理解用户业务环境的**"数据包"**才是持久的资产

### 5.4 未来组织形态

> "任何有远见的人，都能实现它。未来公司可能极度扁平。任何有远见的人都可以像CEO管理十万员工一样指挥庞大的智能体集群。"

**案例：** 系统工程师准备优化文档→丢给模型→去睡觉→醒来发现模型已自己实现初版、加了性能监测、跑了代码、找出瓶颈、迭代多次、拿到结果。

## 六、Jim Fan（NVIDIA 具身智能负责人）

### 6.1 VLA → 世界动作模型(WAM)

- VLA模型本质是"语言偏科生"——擅长理解名词，不懂物理动词
- **WAM（World Action Model）**：像做梦一样在神经网络推演未来几秒画面，再同步输出物理动作
- "只要视频预测不翻车，动作就不会翻车"

### 6.2 Project Ego Scale

- 用 **2.1万小时**人类第一视角视频预训练
- 微调阶段仅混入 **0.1%** 高精度遥操数据
- 即可掌握极其复杂的灵巧手操作（折叠衬衫、使用注射器）
- 标志：**灵巧度缩放定律首次跑通**

### 6.3 预测

> "2040年机器人将能自主设计、改进并制造下一代机器人。"

## 八、其他前沿信号

### 8.1 XBOW — AI安全不对称战场

- Agent 在 HackerOne 全球白帽黑客排行**登顶**
- 仅用一个网址 + 3000美元，攻破微软 Bing 远程代码执行
- "合金模型"策略：攻击每一步交替调用不同模型弥补逻辑错误

## 九、对普通人的启示

### 9.1 编程民主化，但质量门槛没降

> Vibe Coding 让所有人能做出"能跑的东西"，但"能长期维护、能安全运行"仍然需要 Agentic Engineering 的纪律。

### 9.2 稀缺的不是智能，是判断力

| 谁说 | 原话 |
|------|------|
| Karpathy | "你可以外包思考，但不能外包理解" |
| Brockman | "人类注意力是最稀缺资源" |
| 红杉 | "当所有高级智力技能廉价化后，真正让你保持竞争力的是情感" |

### 9.3 新的技术鸿沟正在形成

- 少数人获得 **远超10倍加速**
- 大多数人还在"50/50"中间状态
- 这个鸿沟比编程语言的鸿沟**更难跨越**

### 9.4 最被低估的风险：锯齿状智能

可验证性 = 判断机器接管程度的核心标准：

| 领域 | 可验证性 | AI接管程度 |
|------|---------|-----------|
| 写代码 | ✅ 高（测试能不能过） | 高度接管 |
| 设计界面 | ✅ 中（是否符合规范） | 中度接管 |
| 内容写作 | ✅ 部分可验证 | 中度接管 |
| **创意决策** | ❌ 不可验证 | **仍需人类** |

### 9.5 最后的护城河

> **Vibe Coding 抬高了地板，让所有人都能站上去。**
> **Agentic Engineering 抬高了天花板，让我们知道还有更高的地方值得去。**
> **而连接地板和天花板的，不是对技术的恐惧，而是对"理解"的持续投入：借助 AI 省下时间，去补那些真正属于人的能力。**
