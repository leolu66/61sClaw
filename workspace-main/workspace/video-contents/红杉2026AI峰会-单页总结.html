Speaker Insights

当程序员不写代码之后

Claude Code 之父 Boris Cherny × Software 3.0 提出者 Andrej Karpathy

🧑‍💻

Boris Cherny

Anthropic · Claude Code 创始人

"工程师的价值，从会不会写代码，变成了会不会拆任务、会不会把目标讲清楚、会不会验收结果、会不会管理 Agent。"
  • 2026年至今没手写过一行代码，最高纪录一天 150个PR
  • 大部分工作在手机上完成，常驻5-10个会话、几百个Agent并行
  • Claude Code 自己的代码库，一年后可能只剩 100行
  • 每天几十个 Loop 自动跑：修CI、变基、抓反馈、修不稳定测试
  • MCP = AI 时代的 API，让模型直接理解使用外部工具
  • Computer Use 让AI像人一样操作老旧系统的屏幕和鼠标
  • 创业者黄金时代：公司数量将暴增 10倍
"最合适写会计软件的是会计师而不是工程师，编程是简单部分，懂业务才是难的部分。"
🧠

Andrej Karpathy

前特斯拉 AI 负责人 · Software 3.0 提出者

"上下文窗口就是程序。你扔给模型的那整段上下文就是你对这台大语言模型解释器的杠杆。"
  • Software 3.0：人写提示词，模型本身就是可被自然语言编程的解释器
  • MenuGen案例：拍的菜单照片直接丢给Gemini，一句话渲染菜品图——整层工程结构是多余的
  • 锯齿状智能：会重构10万行代码，却可能在走路/开车的常识问题上犯错
  • Vibe Coding = 抬高地板，让所有人都能做出东西
  • Agentic Engineering = 保住天花板，保证安全与可维护
  • 智能体是"超级实习生"：能力强但会犯错，必须人在循环
  • 新招聘考法：别考手写算法，考能在Agent代码里 保住判断力
"你可以外包思考，但不能外包理解。当所有人都在外包思考的时候，守住自己的理解就是守住最后的护城河。"
🤝

共识：编程已被 AI 基本解决。稀缺的不再是代码能力，而是判断力、产品感觉、领域理解和管理 Agent 的能力。

第二页我们聚焦两位重量级嘉宾的核心观点。 首先是 Claude Code 之父 Boris Cherny。他今年的演讲有一句震撼全场的话：2026年至今我没有亲手写过一行代码。他的工作方式完全变了——大部分在手机上完成，后台几百个 Agent 并行跑，一天最高提交150个PR。他认为编程已经被 AI 基本解决，工程师的价值不再是写代码，而是拆任务、讲清楚目标、管理 Agent。 他还提出了 MCP 协议——AI 时代的 API，让模型直接使用工具。Computer Use 则让AI能像人一样操作老旧系统的界面。 另一位是 Andrej Karpathy。他提出了 Software 3.0 的概念——上下文窗口就是程序，模型本身是可被自然语言编程的解释器。他举了 MenuGen 案例来说明 Software 3.0 的颠覆性：输入一张图，输出一张图，中间不需要任何应用层。 但他也提出了重要的警示——锯齿状智能：AI在代码领域极强，但在日常常识上可能犯低级错误。所以他强调 Vibe Coding 抬高地板的同时，必须用 Agentic Engineering 保住天花板，人在循环中守住判断力。 两人的共识：编程已被解决，稀缺的是判断力、领域理解和产品感觉。
