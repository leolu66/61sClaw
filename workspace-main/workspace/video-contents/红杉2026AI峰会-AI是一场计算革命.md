## 核心观点

### 1. AI ≠ 通信革命，而是计算革命

> 互联网、云、移动端本质是"通信革命"——改变信息的传播方式。AI 是"计算革命"——改变信息的处理方式。这不是更快的问题，而是本质的不同。

- 以往是制造"更快的马"（提升10-40%效率）
- 现在是在制造"**汽车**"（10倍效率，彻底改变工作方式、组织本质）

### 2. 三个转折点 → 商业AGI已来

| 时间 | 标志 | 意义 |
|------|------|------|
| 2022.11 | ChatGPT | 预训练的力量震惊世界 |
| 2024-2025 | o1 模型 | 推理能力 + 第二条缩放定律 |
| 2026 | Claude Code / 长周期智能体 | 代理能自主完成复杂任务 |

> "如果你能指派一个智能体去完成一项工作，它能在遇到故障后自我修复并持续工作直到任务完成——这就是商业意义上的通用人工智能。"

### 3. MADS 框架：在模型之上构建竞争力

- **Moats（护城河）**：关注客户需求，而非技术本身。技术日新月异，客户需求持久稳定
- **Affordance（可供性）**：创造"无需解释"的产品体验，像锤子一样拿起来就知道怎么用
- **Diffusion（扩散）**：基础模型能力远超企业吸收速度，这个"扩散鸿沟"就是应用层公司的巨大机遇

> 附注：口号是"你无法在晴天超越15辆车，但可以在雨天超越15辆车"——新功能如暴雨般涌现，没有领先是稳固的，所有人都有机会。

### 4. 智能体之年：服务即新一代软件

智能体三大组件：
- **模型（大脑）**：任务保持时间从分钟级 → 小时级
- **工具（手脚）**：终端、iMessage、Slack、搜索、计算机使用
- **控制框架（持久性）**：RL训练、自我改进、Agent衍生Agent

智能体进化阶梯：
1. 标签补全（行间辅助）
2. 人 + Agent 对话
3. **异步后台 Agent**
4. Agent 衍生 Agent
5. **黑灯工厂**（无人审查，机器制造机器）
