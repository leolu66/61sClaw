## 遇到的问题

1. **CLI 发送消息返回 exit code 1**
   - 原因：消息发送成功但 CLI 超时
   - 解决：捕获异常，只要消息发出即认为成功

2. **结果文件路径问题**
   - 原因：test-recorder.js 中的相对路径不正确
   - 解决：使用绝对路径 `process.env.USERPROFILE`

3. **sessions_send 向当前会话发送消息超时**
   - 原因：不能向正在运行的会话发送消息
   - 解决：改用 CLI 方案

## 经验教训

1. **端到端测试比单元测试更能验证系统真实行为**
2. **文件系统适合简单的状态同步场景**
3. **测试标记格式要独特，避免与正常消息冲突**
4. **详细文档对后期维护至关重要**
