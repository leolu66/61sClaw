# 工作日志 - 2026-03-14

## 任务概述
开发 NetNotes（互联网笔记本）技能，实现网页文章收藏、分类、标签管理和查询功能。

## 完成内容

### 1. 基础功能开发
- 创建技能目录结构和数据库表（articles, tags, article_tags）
- 实现网页抓取模块（crawler.py），支持静态和动态网页（Playwright）
- 实现文章分类模块（classifier.py），关键词+大模型智能分类
- 实现数据库操作模块（database.py），支持CRUD和标签关联

### 2. 标签功能
- 标签无需预定义，用户输入时自动创建
- 支持一篇文章多个标签
- 实现标签关联表的增删查
- 支持按标签检索文章

### 3. 预览确认流程
- 抓取文章后生成预览文件（Markdown + HTML）
- 临时保存到 temp/ 目录
- 交互式确认分类和标签
- 用户确认后移动到正式目录并入库

### 4. 高级查询工具
- 支持多条件组合查询：关键词、标签、分类、日期范围
- 实现 query.py 工具，支持 search/list/tags/stats/recent/open 命令
- 查询结果支持编号索引，可快速打开文章查看

### 5. 文件管理
- 自动清理文件名非法字符
- 处理重名文件（自动添加序号）
- 移除emoji和控制字符

## 技术要点
- 使用 Playwright 处理动态网页反爬
- SQLite 多表关联查询（文章-标签多对多关系）
- 交互式命令行流程设计
- Windows 控制台编码处理

## 遇到的问题
1. Windows 控制台 UTF-8 编码问题 - 使用 encode('gbk', errors='ignore') 处理
2. SQL 查询表别名不一致 - 统一使用 a.* 别名
3. 文件名特殊字符处理 - 增加正则清理换行符、emoji等

1. 交互式工具比全自动更适合需要用户确认的场景
2. 数据库设计时考虑多对多关系需要关联表
3. Windows 环境下编码问题需要特殊处理
4. 预览模式让用户在保存前有机会确认和修改
