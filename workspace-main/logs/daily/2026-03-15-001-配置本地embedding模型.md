## 技术要点总结

### OpenClaw 本地 Embedding 配置

**配置路径**：
```
agents.defaults.memorySearch.local.modelPath
```

**完整配置**：
```json
{
  "agents": {
    "defaults": {
      "memorySearch": {
        "provider": "local",
        "local": {
          "modelPath": "C:\\path\\to\\model.gguf"
        }
      }
    }
  }
}
```

**依赖要求**：
1. **sqlite-vec** (Python): `pip install sqlite-vec`
2. **node-llama-cpp** (Node.js): `npm install -g node-llama-cpp`

**模型格式**：
- 只支持 **GGUF** 格式
- 不支持 PyTorch (.bin) 或 ONNX 格式

### 搜索模式对比

| 模式 | 说明 | 依赖 |
|------|------|------|
| `fts-only` | 纯文本搜索（BM25） | sqlite-vec |
| `hybrid` | 向量 + 文本混合搜索 | sqlite-vec + node-llama-cpp + GGUF模型 |
