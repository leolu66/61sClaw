## 关键决策与成果

### 关键决策

| 决策 | 说明 | 原因 |
|------|------|------|
| 采用浏览器自动化方案 | 使用 Playwright 控制浏览器模拟人工操作 | FOL 系统有反爬虫机制，直接 API 调用困难 |
| 分离 fol_importer 模块 | 将 FOL 相关功能独立成模块 | 便于维护，与发票抓取逻辑解耦 |
| 人工辅助验证码 | 登录时暂停等待人工输入验证码 | FOL 验证码较复杂，自动识别成本高 |
| 基于行程日期搜索发票 | 根据行程开始日期自动计算搜索范围 | 提高发票匹配准确性，减少无关结果 |
