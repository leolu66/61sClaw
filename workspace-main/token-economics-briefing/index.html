05 / 12
Shadow Price
影子价格的跨层演化
影子价格 $\tilde{P}$ 随系统规模扩张而演化，统一了从微观推理到宏观生态的分析框架：
Phase I · 单 Agent
P̃ = Pm + w · τinf
推理时延或工具调用开销
Phase II · 多 Agent
P̃ = Pm + w · τsync + ΔCcoord
Agent 间同步时延 + 格式对齐协调成本
Phase III · 生态系统
P̃ = Pm + w · τcong + Ccomp
拥塞时延 + 合规与环境外部性成本
核心洞察：影子价格将时间延迟、协调摩擦、拥塞和合规成本都转化为可量化的经济支出，使跨层优化有统一度量标准。
Pm = 每词元采购价格   w = 时间机会成本   τ = 时延
