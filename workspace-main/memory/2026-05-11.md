##  晚间：video-extractor 技能创建

### 重要工作

- 创建 `video-extractor` 技能：从国产平台视频 URL 提取文本内容
- 流程：yt-dlp 下载音频 → Whisper 语音识别 → LLM 清洗后保存
- 支持头条、抖音、快手、B站等 yt-dlp 兼容平台

### 错误记录和反思

- **关键教训**：回复中展示的清洗版本必须与保存的文件内容一致，不能自行脑补修正后展示不同版本
- Medium 模型在 CPU 上运行极慢（1.5GB，30分钟跑不完47秒视频），不实用

### 开发经验总结

- 视频内容提取流程：small模型快速转录 + LLM清洗 = 实用方案
- `output/` 目录保存 raw 输出，agent 再读文件做 LLM 清洗后覆盖
- 语音识别结果需要后处理：繁体→简体、加标点、纠同音字错误
