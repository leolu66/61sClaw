Problem

三大困境

传统民乐教育长期依赖"口传心授"模式，在数字化浪潮中面临系统性挑战。

"韵味、气韵、意境——民乐独特的审美维度，在标准化的技术工具面前，面临被降维的风险。"
— 本研究 · 核心关切
困境一 · 师资瓶颈

民乐演奏名师稀少，一对一口传心授难以规模化；跨学科师资（民乐+AI+教育学）更是凤毛麟角。

困境二 · 评测主观

演奏评估缺少客观量化标准，音准、节奏可测，但"韵味""气韵"等核心审美维度难以量化。

困境三 · 数字化缺位

大量民族音乐作品音视频资料难以查询，缺乏系统的数字资源平台；现成民乐数据集标注维度单一，缺少韵味标签。

Challenges · 关键瓶颈

挑战与
争议并存

技术可行性与文化本体性之间的张力，是数字民乐教学体系必须直面的核心矛盾。

"AI不应被定位为韵味的评判者，而应作为韵味的解析与展示工具。"
— 本研究立场
认识论争议

AI能否捕捉"韵味"本质？量化表征是否会导致民乐文化内涵的降维与异化？

数据稀缺

CCMUSIC等数据集标注维度单一，缺韵味/风格标签；CTIS协议限制商业使用。

人才断层

同时懂民乐+AI+教育学的复合型人才极少，跨学科师资培养体系尚未建立。

教育伦理

AI评分对学生艺术个性的压制风险；教师角色如何在人机协同中重新定位。
