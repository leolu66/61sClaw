# Anthropic 2026 全球开发者大会：与 SpaceX 算力合作演讲

## 核心内容

### 1. 与 SpaceX 的算力交易

- Anthropic CEO Dario Amodei 宣布与 Elon Musk 的 SpaceX 达成协议
- 将使用 SpaceX 位于田纳西州孟菲斯的 **Colossus 1** 数据中心全部算力
- 该数据中心拥有超过 **22 万个英伟达 GPU**
- 在未来 1 个月内带来 **超过 300 兆瓦** 的新增容量
- Anthropic 还表示"有兴趣合作开发**数吉瓦级的轨道AI算力**"（太空数据中心）

### 2. 新功能发布：Claude "Dreaming"（做梦）

- 帮助 AI 系统在会话之间通过学习来改进
- 自动识别模式并更新存储用户偏好和其他上下文的文件
- 面向软件开发者和企业客户

### 3. Claude Code 全面升级

- 付费计划的 **速率限制翻倍**
- Pro 和 Max 账户取消高峰时段使用限制
- 大幅增加开发者对 Claude Opus 模型的请求量

### 4. 马斯克态度反转

- 此前马斯克多次批评 Anthropic（称其"憎恨西方文明"、"注定变得厌人类"）
- 此次合作前，马斯克与 Anthropic 高层相处一周后态度反转
- 马斯克在 X 上发帖："我遇到的每个人都非常有能力，非常关心做正确的事情"
- 同时宣布 xAI 将作为独立公司解散，更名为 **SpaceXAI**

### 5. 背景信息

- SpaceX（已与 xAI 合并）正在利用 Colossus 1 向 AI 算力租赁市场扩张
- Anthropic 正以 9000 亿美元估值寻求融资
- Anthropic 此前已与亚马逊签署数十亿美元的算力协议
- 公司与美国政府关系紧张：五角大楼 3 月将 Anthropic 列入供应链风险黑名单
- Colossus 1 的天然气涡轮机引发孟菲斯当地空气污染争议
