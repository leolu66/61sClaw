●● Claude 从"聊天"进化到"团队"

Managed Agents

🌙 Dreaming · 离线进化
在会话之间自动后台运行：回顾经验、提取模式、整理记忆。像人类做梦一样巩固有用信息、丢弃噪声，Agent 随运行时间自动变强
🎯 Outcomes · 目标驱动
编写 rubric 定义成功标准，独立评分 Agent 评估输出质量，不达标自动打回重做。分离评审与执行，保障交付质量
🔄 Multi-Agent · 多 Agent 编排
主 Agent 拆解任务→调度多个子 Agent 并行执行→汇总结果。类似 Kubernetes 调度容器，但调度的是 AI Agent
⤷ 三大 Agent 新能力
Code ReviewAI 自主审查 + 修复自动提交修复 PR，CI 流程自主发现问题
Remote Agents跨系统远程操作远程控制外部系统完成任务
