# AI新闻简报模板

> 本模板用于 `ai-news-briefing` 技能，生成面向运营商运营支撑系统的AI新闻简报。

## 简报输出模板

```markdown

**数据源**：36氪AI / AiBase / InfoQ / AI科技评论 / 量子位 / 智东西 / 极客公园 / 多维度聚合

---
```

## 分析关注维度

分析新闻时重点关注以下与运营商相关的维度：

| 维度 | 关键词 | 对应模板章节 |
|------|--------|-------------|
| 客服智能化 | 客服、坐席、联络中心、数字员工、Agent | 机会-智能客服 |
| 运维自动化 | 运维、自动化、故障诊断、监控、流程 | 机会-运维分析 |
| 知识库问答 | 知识库、RAG、问答、文档、检索 | 机会-知识问答 |
| 私有化部署 | 私有化、本地部署、安全、合规、信创 | 风险-数据安全 |
| 大模型应用 | 大模型、LLM、GPT、DeepSeek、智谱 | 趋势判断 |
| 成本优化 | 成本、降本、轻量化、推理优化 | 机会-成本优化 |
| 政策治理 | 监管、法规、安全、审计 | 风险-合规 |
| 竞品动态 | 友商、华为、容联云、AI厂商 | 风险-竞品 |

## 新闻分类标准

| 分类 | 定义 | 示例 |
|------|------|------|
| **技术/产品** | 新技术发布、模型升级、产品推出 | 新模型发布、Agent平台上线 |
| **行业应用** | 具体行业落地案例 | 运营商AI项目、企业部署 |
| **竞争动态** | 竞品动作、市场格局变化 | 友商发布AI方案 |
| **政策治理** | 法规政策、安全要求 | 欧盟AI法案、国内监管 |
| **市场信号** | 融资、合作、市场趋势 | 大额融资、战略合作 |
