# 专题研究总结 (Topic Research Summary)

## 需求说明（SRS）

### 触发条件
用户表达想做"专题研究"或"汇总多篇文章/视频/文档"为一份报告：
- "帮我研究一下 XXX"
- "做个专题研究：XXX"
- "把这些资料汇总成一份报告"
- 提供了研究主题 + 多篇文章链接

### 功能描述
将分散的多篇素材（网页、视频字幕、文档等）聚合成一份结构化综合报告，并可选生成HTML PPT演示文稿。覆盖完整工作流：搜索 → 收集 → 转MD → 汇总 → 生成报告 → 生成PPT → 扩展。

### 输入
- **研究主题**：必填，如"红杉AI 2026峰会"
- **素材来源**（一种或多种组合）：
  - 网页 URL 列表（用户直接提供）
  - 视频 URL（通过 video-extractor 等提取字幕）
  - 文档文件（PDF/MD/HTML/Word 等，转 MD 后使用）
  - 用户直接粘贴的文本
  - 搜索结果（通过搜索技能获取）

### 输出
- `raw/` — 所有原始素材的 MD 版本
- `workspace/<主题名>-综合笔记.md` — 结构化综合报告
- `workspace/<主题名>-单页总结.html` — 精炼 HTML PPT（可选）

### 依赖条件
- **依赖技能**：html-ppt-skill（L2，生成PPT时使用）
- **内置工具**：web_search、web_fetch（搜索和获取网页内容）
- 无需额外安装

### 边界情况
- 单一主题时直接输出一份综合报告
- 多主题时按主题拆分，每个主题独立一份报告
- 搜索结果不全时提示用户补充链接
- 网页需登录时尝试其他来源或提示用户

## 完整工作流（6步）

```
用户给研究主题
    │
    ▼
Step 1: 确认主题，创建目录结构
    │
    ▼
Step 2: 启动搜索，获取初步素材
    │
    ▼
Step 3: 收集用户提供的链接/文档 → 转MD → 保存 raw/
    │
    ▼
Step 4: 汇总分析 → 按主题生成综合报告(MD)
    │
    ▼
Step 5: 生成精炼 HTML PPT（默认1页，可多页）
    │
    ▼
Step 6: 根据用户反馈扩展/修改 PPT
```

---

## Step 1: 确认主题，创建目录

收到研究主题后：

1. 确认主题名称（用于目录和文件命名）
2. 创建素材目录：
   ```
   workspace/<主题名>/
   └── raw/           # 存放所有原始素材(MD)
   ```

3. 确认输出路径：所有文件放在 `workspace/<主题名>/` 下

---

## Step 2: 搜索初步素材

根据主题关键词进行搜索：

**中文内容** → 使用 `web_search` 搜索
**英文/国际内容** → 使用 `web_search` 或以英文关键词搜索

搜索策略：
- 先用核心关键词搜索，取前 5-8 条结果
- 浏览结果摘要，筛选相关度高的链接
- 将搜索结果摘要呈现给用户，让用户确认方向

**如果用户跳过搜索，直接提供链接** → 跳过此步。

---

## Step 3: 收集素材 → 转MD → 保存 raw/

### 3.1 网页 URL
对每个用户提供的 URL，使用 `web_fetch` 获取内容，保存为 MD：

```
workspace/<主题名>/raw/<来源简称>.md
```

- 文件名用来源简称（如 `百家号-文章标题.md`）
- 在 MD 文件头部注明：来源URL、获取日期

### 3.2 视频 URL
- YouTube → 使用 video-transcript-downloader 提取字幕
- 国内平台 → 使用 video-extractor 提取字幕
- 如无字幕，搜索媒体对该视频的文字报道

### 3.3 文档文件（PDF/MD/HTML/Word）
- PDF → 使用 `web_fetch` 或 pdf-extract 转 MD
- Word → 读取后转 MD
- 其他 → 同理转 MD 后保存到 raw/

### 3.4 用户直接粘贴的文本
直接保存为 MD 文件到 raw/

**重要：每一步获取到内容后，即时告知用户素材已保存及文件路径。**

---

## Step 4: 汇总 → 生成综合报告

完成素材收集后，开始汇总分析：

### 4.1 通读所有 raw/ 下的素材

### 4.2 识别内容结构
- 确定核心主题和子主题
- 识别不同文章之间的互补/重复关系
- 提取每篇的增量信息（新于已有内容的部分）

### 4.3 组织报告结构
报告文件：`workspace/<主题名>/<主题名>-综合笔记.md`

```
# [主题名称] — 综合笔记

> 资料日期 | 来源清单

---

## 一、[子主题1]
（整合所有来源的相关内容）

## 二、[子主题2]
...

## N、总结/启示
```

### 4.4 内容整合原则
- **去重**：多篇文章重复的观点只保留最完整的版本
- **互补**：不同文章提供的增量信息按逻辑归入对应章节
- **标注来源**：关键数据/引言标注出处
- **结构清晰**：按人/按话题/按时序组织，优先选最适合主题的结构

### 4.5 输出
保存到：`C:\Users\luzhe\.openclaw\workspace-main\workspace\<主题名>\<主题名>-综合笔记.md`（完整绝对路径告知用户）

---

## Step 5: 生成 HTML PPT

基于综合报告，使用 html-ppt-skill 生成精炼 PPT：

### 5.1 确定页数和结构
- **默认 1 页**：主题标题 + 核心要点网格 + 底部数据条
- **内容较多时**：可拆分 2-3 页（如：核心观点 + 大咖观点）

### 5.2 选择主题
- AI/科技类 → `aurora`
- VC/投资类 → `pitch-deck-vc`
- 技术分享 → `tokyo-night`、`blueprint`
- 正式汇报 → `corporate-clean`、`swiss-grid`
- 可注册多个主题到 `data-themes` 属性供切换

### 5.3 制作流程
1. 参考 html-ppt-skill 的模板结构
2. 选择合适布局（单页用 cover+bullets 组合，多页参考 full-deck 模板）
3. 将报告内容精炼为 PPT 要点
4. 添加动画和演讲者笔记
5. 生成 HTML 文件

### 5.4 文件位置
使用 html-ppt-skill 的 `assets/` 相对路径引用：
- CSS：`../../assets/base.css`、`../../assets/themes/xxx.css`
- JS：`../../assets/runtime.js`

PPT 文件保存到：
```
C:\Users\luzhe\.openclaw\workspace-main\workspace\<主题名>\<主题名>-单页总结.html
```

---

## Step 6: 扩展 PPT

根据用户反馈调整：
- **加页**：新增内容页，更新 `data-total` 翻页
- **改布局**：调整卡片/列数/样式
- **换主题**：切换 `data-themes` 列表
- **加演讲者笔记**：补充 `<div class="notes">` 逐字稿

每次修改后告知用户文件路径。

## 注意事项

1. **文件路径必须告知用户** — 每次产出一个文件，给出完整绝对路径，方便用户查看
2. **素材即时保存** — 获取到网页内容后立即保存到 raw/，不要等全部获取完再存
3. **报告结构先确认** — 生成综合报告前，可先向用户展示目录结构确认
4. **PPT 默认精炼** — 每页 PPT 要点控制在 6 个以内，避免信息过载
5. **多次补充素材友好** — 支持用户陆续追加新链接，追加后更新综合报告和PPT
