5月28日，Anthropic 发布了 Claude Opus 4.8 和一个重磅功能——动态工作流。简单说，就是 Claude 根据你的任务，自己写一个 JavaScript 编排脚本，然后在后台并行运行最多一千个子代理。以前要一轮一轮手动引导，现在，计划变成了代码。中间结果存在脚本变量里，只有最终答案回到对话上下文。这意味着，代码库级别的 Bug 大扫除、大规模代码迁移、安全审计这些以前做不到的事，现在一次运行搞定。Bun 的创建者用它11天生成了75万行 Rust 代码。不过，目前还是研究预览阶段，令牌消耗也比常规对话高5到10倍。企业评估，建议从安全、数据主权、成本和运维四个维度入手，先在支持性工作流上验证，再向核心业务推广。
